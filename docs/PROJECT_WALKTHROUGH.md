# 项目讲解：从运动学模型到棋子抓放

## 一分钟介绍

这是一个以棋子抓取和放置为应用的团队机器人项目。系统把棋盘格坐标转换为机械臂目标位置，通过运动学和逆运动学求解关节配置，再结合舵机标定与串口通信完成实机执行。项目既有自动抓放序列，也有摇杆交互控制。技术主线是工作空间分析、带姿态约束的逆运动学、抓放动作分解，以及模型到硬件的集成。

## 推荐展示顺序

1. **实机视频**：先展示自动抓放，再简要展示摇杆控制，交代实际任务。
2. **工作空间图**：说明棋盘相对基座的位置为何需要与可达范围一起分析。
3. **URDF 姿态图**：说明到达同一目标附近时，夹爪方向、肘部高度和关节限制同样重要。
4. **轨迹图**：说明抓放被分解为接近、抓取、抬升、转移、释放和撤离。
5. **核心代码**：打开 `chessMoveModule.m`，讨论逆解、标定与执行如何连接。

## 可深入讨论的技术点

- **逆运动学**：使用阻尼最小二乘更新，结合步长限制、关节限制和姿态偏好，改善数值求解和抓取姿态选择。
- **预计算**：将重复目标的逆解提前计算并缓存，执行阶段复用配置；缓存需要与机械臂标定及棋盘几何保持一致。
- **实机集成**：模型关节角与舵机指令之间需要处理零点偏置、旋转方向、通信和反馈。
- **工程边界**：工作空间可达不等于整条路径无碰撞；现有姿态约束不等于完整碰撞检测。

## 表述范围

这是团队项目，个人负责部分应根据实际分工介绍。仓库可以支持对实现方法和演示结果的讨论，但没有汇总抓取成功率、定位精度或运行周期等量化测试，不宜给出未经测量的数值。相机工具提供棋盘视图与人工选步接口，不应表述为完整自主视觉对弈系统。
