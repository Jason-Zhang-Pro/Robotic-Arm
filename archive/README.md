# Development Archive

Earlier modeling and control iterations are preserved here for technical reference. The integrated chess application is in `projects/06-chess-robot/`.

- `experiments/a0`–`a3`: modeling, Jacobian, and trajectory iterations.
- `experiments/a4positionfinal`: position-control implementation.
- `experiments/a4velocitycontrol` and `a4velocityfinalv2`: velocity-control implementations.
- Other A4 directories: calibration, compensation, tilt, joystick, and demonstration iterations.

Directory names reflect development history. Load one variant at a time in MATLAB to avoid duplicate function names.
